# 嵌入式秋招学习站

按照先前的《思路.md》方案建立的中文 MCU + FreeRTOS 学习网站。

## 当前内容

- 新增“秋招投递”工作台：300 家公司候选目录、官方或官方委托招聘入口、MCU/RTOS 优先及汽车/Linux/BSP/芯片应用备选标注。
- 招聘快照为 2026-10-03，毕业届次暂按 2027。19 家有本科相关岗位依据，其中部分入口仍需确认毕业窗口；其余 281 家的本届嵌入式学历和学校条件尚待核对。**这不是 300 家全部符合双非本科与千人规模要求的已核实名单。** 页面对未知条件明确标注，不能据此保证简历通过。
- 已在本地读取用户投递表并排除已识别公司及别名；原表、私人排除文件和个人备注不随源码或网站公开。
- 按北京时间生成每天最多 15 家的稳定计划；已投公司不跨日重复。候选公司需先核对本届岗位并勾选确认，才加入计划；不足 15 家时明确显示缺口。
- 投递、笔试、面试、Offer、跳过、个人备注与每日计划仅存当前浏览器；支持 JSON 导入导出、恢复清单及撤销误标。切换浏览器需手动导入备份，网站不会自动投递简历。

- 13 个模块、126 节课程、437 道选择题（378 道基础题 + 59 道进阶笔试题）。
- 40 道代码阅读、填空计算、找错改错与简答设计题，提供答案草稿、默认折叠的推导与评分点。
- 专题练习可按模块、基础/进阶/挑战难度与题型筛选，默认进入进阶练习；新题同时挂到对应知识点。
- 每课按“基础讲解 → 基础随堂题 → 图解与推导例题 → 进阶随堂题 → 编程”穿插显示。练习直接嵌在课程正文中，取消课程视图、题型切换及课程内练习跳转入口；原有题目、答案、学习记录和草稿保留。
- 编程题左侧展示题目、样例和折叠解析，右侧编写代码；手机上自动上下排列。支持保存独立草稿、复制和下载代码，课程内与独立编程页共用同一份草稿。
- 所有选择题调整显示选项，正确选项 A/B/C/D 分布为 110/109/109/109；内部保留原选项索引，历史作答与错题记录继续有效。
- 新增 11 节按顺序学习的 C 入门课，从变量、字节、赋值开始，再解释 `sizeof`、`&`、指针声明、`*p`、数组、函数与结构体；最小例子配符号说明和逐行阅读。
- 其他 10 个基础模块在目录页提供术语入门。C 高频课程补充基础讲解，较难的笔试规则默认折叠。
- 每课都有三步原理解释、易混点及一个推导例题，共 126 道例题，解析默认折叠。
- 56 道手写与场景练习，覆盖波谷、滑动窗口、旋转二分、链表入环点、单调栈、BST、动态规划、溢出检查、位操作、跨回绕计时、协议解析及资源所有权。
- Linux 独立模块新增 10 节从零讲解：程序/进程/线程、命令与权限、fork、exec、waitpid、fd/dup2、IPC、epoll、设备树和驱动；原 Linux 总览保留。
- 新增 3 节 RTOS 课程：Ready 集合与饥饿、优先级反转/继承、NVIC 与任务优先级的区别。限定单核抢占式与具体 Cortex-M 条件，讲清阈值和移位编码。
- 波谷专题明确严格/平台/最长连续区间三种定义，提供 4 份 C/C++ 算法参考解和逐步折线图；另有 1 份 Linux fork/exec/wait 编程练习。本次练习均为原创，不声称复现用户未提供题干的笔试原题。
- 新增 22 道随堂编程：12 道 C11、10 道 C++17，包含原地数组处理、字符串、二级指针删除链表、回调、重叠搬移、结构体排序，以及构造析构、深拷贝/移动、RAII、STL、模板、RTTI和多态复制。全部 9 节 C++ 课程都有对应编程练习。
- 相关算法题附力扣或牛客原题链接；本站题干、样例、解法与说明为独立编写，适用约束和原题不同处在题内注明。
- 58 节课程有图示；其中 34 节提供逐步执行、当前代码、变量监视、前后步进与重置。
- 详细推演覆盖指针、二维数组、结构体填充、链表反转、树先序、二分、冒泡、环形队列、SPI 四模式、CAN 仲裁、优先级继承、队列所有权、DMA、时钟树、STOP1 与周期延时。
- 答案默认隐藏。选择并提交或点“不会？查看解析”后，才显示答案与解析。
- 专题练习、错题复习、20 分钟模拟笔试、搜索、学习进度、代码草稿及导入/导出。

目前完成了方案中的基础主线和主要高频主题。方案预计的 180～220 节课程、800～1200 道练习属于后续扩充目标，网页按实际内容显示数量。

## 本地运行

在本目录运行：

```powershell
python -m http.server 8000 --directory dist
```

然后在浏览器打开 `http://localhost:8000`。网页是静态文件，无需安装 npm 依赖。不要双击 `index.html` 直接打开：浏览器通常会限制 `file://` 页面加载 JS 模块。

- `dist/exam-challenges.js`：新增编程题、参考解、边界检查及平台原题链接。

## 检查

```powershell
node --check dist/content.js
node --check dist/challenges.js
node --check dist/app.js
node scripts/smoke.mjs
node scripts/check-recruitment.mjs
```

`smoke.mjs` 会遍历所有课程与练习页，检查答案初始隐藏、解析展示和错题重做流程。

它还验证全课程原理覆盖、题目 ID、链表反转连接、树遍历顺序、排序结果、二分保留目标以及四种 SPI 采样规则。

新增检查覆盖显示答案字母分布、难度/题型筛选、进阶题判分与历史索引。

`node scripts/check-expansion-code.mjs` 编译网页中的 4 份波谷参考解，对 9,841 个长度 0～8、取值 -1/0/1 的数组与独立暴力解法对拍，并检查整数极值和样例。在 Linux 上还会编译运行 fork/exec/wait 参考解的退出状态测试；Windows 上明确跳过该运行测试并生成 Linux 测试源码。当前机器的 Ubuntu 未提供 C 编译器，本次未验证真实 Linux 运行路径，未安装额外编译器。

`node scripts/check-lesson-code.mjs` 直接读取网页的 22 份新增参考解，分别按 C11、C++17 编译，测试分配失败、重叠搬移、输出别名、深拷贝、移动、自赋值、异常释放与队列回绕。默认使用当前电脑的 CLion MinGW；可通过 `CC`、`CXX` 指定编译器路径。

安装了 C++17 编译器时可运行 `node scripts/check-exam-code.mjs`。脚本直接读取网页里的 12 份新增参考解，编译并测试短字符串穷举、各旋转数组、链表环入口、单调栈、解析边界、位操作及移动所有权。默认使用当前电脑的 CLion MinGW；其他电脑将 `CXX` 设为本地编译器路径即可。生成文件放在被 Git 忽略的 `.sites-runtime` 中，网站本身无需编译器。

Windows 上安装了默认位置的 Chrome 时，可运行 `node scripts/browser-check.mjs`。脚本使用独立浏览器目录和本地服务器，检查真实页面的例题折叠、步进/重置、四种 SPI 模式以及 390 px 手机布局，截图保存在项目上级的 `tmp/reading-qa`。可在脚本中调整 Chrome 路径；这不是网站运行依赖。

投递检查还覆盖稳定计划、不重复推荐、候选确认、状态与备注刷新保留、备份恢复以及桌面和手机布局。`check-recruitment.mjs` 检查 300 家 ID、名称与 URL，以及计划和导入校验；可选第二个参数传本机私有排除名单路径，只读检查、不上传。
